# AX 파트너 — 블로그 → SNS 3채널 변환 스킬

## 이 스킬이 푸는 문제

블로그 글을 SNS에 그대로 복사·붙여넣기 하면 세 채널이 전부 죽는다. 세 채널의 **역할이 서로 다르기** 때문이다.

| 채널 | 역할 | 독자가 하는 행동 |
|---|---|---|
| **쓰레드** | 인지·대화 | 읽고 댓글 단다 (링크는 잘 안 누른다) |
| **인스타** | 저장·브랜딩 | 저장하고 나중에 본다 (링크를 못 누른다) |
| **페이스북** | **유입** | 링크를 눌러 블로그로 넘어온다 |

그래서 재료는 하나(블로그 1편)지만 가공은 3번 따로 한다. 이걸 **"1블로그 : 3변주"** 라고 부른다.

타겟 독자는 **10~50인 제조·유통·D2C 중소기업 대표**다. 개발자·마케터가 아니라 사장님이 읽는다는 걸 잊지 않는다.
모든 채널의 최종 목적지는 **axpartner.co.kr 무료 AI 수준 자가진단**이다.

## 작업 순서

### 0단계 — 입력 확보

사용자가 준 것에 따라 갈린다.

- **블로그 원고(.md·텍스트)를 줬다** → 그대로 읽는다.
- **블로그 URL만 줬다** → WebFetch로 본문을 가져온다. 실패하면 원고를 붙여넣어 달라고 요청한다.
- **소재·주제만 줬다** ("Shadow AI로 SNS 만들어줘") → 블로그 글 없이도 만들 수 있다. 다만 페이스북은 링크할 글이 없으므로, 연결할 블로그 글이 있는지 먼저 확인한다. 없으면 페이스북은 링크 없는 게시글로 만들고 CTA를 자가진단으로 돌린다.
- **채널을 지목했다** ("쓰레드만") → 해당 채널만 만든다. 다만 나머지 2채널도 만들어둘지 한 줄로 물어본다. 재료 추출은 이미 끝났으니 추가 비용이 거의 없다.

### 1단계 — 재료 4가지 추출 (여기가 전부다)

원고를 다 읽고 아래 4개를 먼저 뽑아 사용자에게 보여준다. **이 4개만 정확하면 3채널이 자동으로 나온다.** 반대로 여기서 밋밋한 걸 뽑으면 뒤에 뭘 해도 살아나지 않으니, 원고에서 가장 날 선 문장을 고르는 데 시간을 쓴다.

```
📦 추출한 재료
1. 핵심 주장 1줄 : [반박하고 싶어지는 문장일수록 좋다 → 쓰레드]
2. 실무 팁 3~5개 : [번호 매길 수 있는 형태 → 인스타 카드]
3. 사례 or 숫자 1개 : [출처 포함 → 페이스북 도입부]
4. CTA : [무료 AI 수준 자가진단 / axpartner.co.kr]
```

**"핵심 주장"을 고르는 기준**: 사장님이 읽고 "어? 정말?" 하거나 "맞아, 우리도 그래" 하는 문장. 교과서적인 정의문("AX란 ~입니다")은 블로그에선 좋지만 SNS에선 스크롤을 못 멈춘다.

**숫자를 쓸 때**: 출처가 확인된 것만 쓴다. 원고에 출처 없는 수치가 있으면 SNS로 옮기지 말고, 대신 사례나 비유를 쓴다. 출처 없는 숫자는 SNS에서 훨씬 빨리 문제가 된다 — 캡처돼서 돌아다니기 때문이다.

### 2단계 — 채널별 원고 작성

아래 "채널별 제작 규칙"을 따른다.

### 3단계 — 자가 점검 후 출력

맨 아래 체크리스트로 스스로 점검한 뒤, `.md` 파일 하나로 저장하고 사용자에게 전달한다.

파일명: `SNS_[핵심키워드]_[YYYYMMDD].md`

## 채널별 제작 규칙

### 쓰레드 (Threads)

**규격**: 게시물당 최대 500자. 하지만 **실전 권장은 50~150자**다. 짧게 끊어 **이어달기(연속 게시)** 로 붙이는 쪽이 훨씬 잘 퍼진다. 토픽태그는 **1개만** 달린다(인스타식 해시태그 나열 불가).

**구조** — 3~4개 이어달기:

```
[1] 반박 여지 있는 주장 1줄
    ↓ 빈 줄
    왜 그런지 2~3줄, 구어체

[2] 근거·사례 (숫자가 있으면 여기)

[3] 그래서 뭘 하면 되는지 1~2줄

[4] 질문으로 마무리 — 대화 유도

토픽태그: #AI전환  (1개만)
```

**링크는 본문이 아니라 첫 답글에 단다.**
`자세한 건 여기 정리해뒀습니다 👉 [블로그 URL]`

**톤이 전부다.** 쓰레드는 브랜드 계정이 홍보 톤으로 말하는 순간 외면당한다. "AX 파트너입니다. 오늘은…"이 아니라 **"현장에서 이런 걸 봤습니다"** 하는 1인칭 관찰자 톤으로 쓴다. 대표 개인이 말하는 것처럼. 마케팅 문구(", 지금 바로!", "필수!")를 넣지 않는다.

### 인스타그램 카드뉴스

**규격**: 1:1(1080×1080) 또는 4:5(1080×1350). **4:5가 피드 점유 면적이 커서 기본값으로 권한다.** 5~7장.

**구성**:

| 장 | 역할 | 카피 원칙 |
|---|---|---|
| 1 (표지) | 스크롤 정지 | 숫자 + 문제. 15자 이내 |
| 2 | 왜 지금 이게 중요한가 | 2줄 |
| 3~6 | 실무 팁 1개씩 | **카드당 한 문장 + 부연 1줄** |
| 7 (CTA) | 자가진단 유도 | "우리 회사는 몇 점일까? → 프로필 링크" |

한 장에 두 가지를 넣지 않는다. 카드뉴스는 손가락으로 넘기며 보는 매체라 한 장당 1초다.

**캡션** — 첫 2줄이 전부다(나머지는 "더 보기"로 접힌다):

```
[핵심 문장 1줄]
[궁금증 유발 1줄] 👇

(본문 3~5줄)

프로필 링크에서 무료 AI 수준 자가진단 받아보실 수 있습니다.

#중소기업AI #AI전환 #AX #중소기업경영 #스마트공장 #AI활용 #사장님공부 (5~10개)
```

**링크가 안 걸린다는 게 인스타의 핵심 제약이다.** 7번 카드 CTA와 프로필 링크가 반드시 같은 곳(자가진단)을 가리켜야 한다. 여기가 어긋나면 전환이 통째로 새어나간다. 출력할 때 "프로필 링크가 자가진단으로 되어 있는지 확인하세요"를 한 줄 적어준다.

**이미지 산출물 — 나노바나나(제미나이)로 한글까지 박힌 완성 카드를 바로 뽑는다.**

실제 이미지를 만들었다고 말하지 않는다. **복붙용 프롬프트까지가 산출물이다.**

예전에는 "배경만 AI로 뽑고 한글은 Canva에서 얹으라"고 안내했다. **폐기된 지침이다.** 나노바나나(제미나이 3 Pro Image)는 한글을 포함한 여러 언어 텍스트를 오타 없이 렌더링하고 4:5·16:9 비율을 지원한다. Canva를 거치면 사용자가 도구를 하나 더 열고 글자 위치를 손으로 맞춰야 하는데, 그 단계가 실제로 콘텐츠를 멈추게 만드는 지점이다. 그래서 **한글 카피를 프롬프트 안에 넣어 완성 이미지를 바로 받는 것을 기본값으로 한다.**

**사용자의 작업은 "붙여넣기" 하나뿐이어야 한다.** 사용자는 gemini.google.com에 이미 로그인해 두고 프롬프트를 순서대로 붙여넣기만 한다. 그러니 프롬프트에 `[여기에 카피 입력]` 같은 빈칸을 남기지 않는다. 실제 카피가 박힌 완성 프롬프트를 준다.

**프롬프트 작성 규칙**

1. **자연어 서술문으로 쓴다.** 미드저니식 키워드 나열(`photo, 50mm, moody, 4:5`)은 나노바나나에서 오히려 결과가 나쁘다. 장면을 사람에게 설명하듯 문장으로 쓴다.
2. **한글 카피는 큰따옴표로 정확히 지정하고, 그대로 쓰라고 못 박는다.** 예: `Render the Korean text exactly as written, with no spelling changes: "직원 몰래 쓰는 AI"`. 이 문장이 없으면 모델이 한글을 임의로 바꾸거나 영어로 옮긴다.
3. **글자 위치와 크기를 지시한다.** "상단 3분의 1에 굵은 흰 글씨" 식으로. 안 그러면 글자가 인물 얼굴 위에 올라간다.
4. **비율을 문장으로 명시한다.** 인스타 카드는 `4:5 aspect ratio`, 페이스북 OG는 `16:9 aspect ratio`.
5. **1번 카드는 풀 프롬프트, 2번부터는 이어쓰기 프롬프트로 준다.** 나노바나나는 같은 대화 안에서 스타일을 이어받는다. 매번 전체 설명을 반복하면 오히려 스타일이 흔들린다.

**출력 형식** — 코드블록 하나가 붙여넣기 한 번이다. 블록 안에 설명이나 주석을 섞지 않는다.

```
🖼️ 카드 1 — 표지 (4:5)
```
세로 4:5 비율의 사실적인 사진을 만들어줘. 한국의 작은 사무실에서 야근 중인 직장인이
뒷모습으로 노트북 앞에 앉아 있고, 화면 불빛만 얼굴 옆을 비추는 어두운 분위기.
사진 상단 3분의 1은 어둡게 비워두고, 그 자리에 굵은 흰색 고딕체로 다음 한글 문구를
철자 그대로, 오타 없이 넣어줘: "직원 몰래 쓰는 AI"
그 아래 조금 작은 글씨로: "사장님만 모릅니다"
글자는 인물과 겹치지 않게 배치하고, 로고나 다른 글자는 넣지 마.
```

```
🖼️ 카드 2 — (같은 대화에 이어서 붙여넣기)
```
방금과 똑같은 사진 스타일과 글씨체를 유지하면서, 배경만 밝은 아침 사무실 책상으로
바꿔줘. 상단 문구를 이걸로 교체해줘: "금지시키면 안 쓸까요?"
아래 작은 글씨: "개인 폰으로 씁니다"
```

**한글이 깨지면** 그때만 Canva를 폴백으로 안내한다. `no text, no letters` 를 넣어 배경만 다시 뽑고 카피는 Canva에서 얹으면 된다. 처음부터 이걸 기본으로 제시하지 않는다.

### 페이스북

**규격**: 링크 첨부 게시글 + OG 이미지 1200×630. **본문 3~5줄**(마무리 안내와 링크 줄은 여기서 제외하고 센다). 해시태그 0~2개 — 페이스북은 해시태그 효과가 거의 없고, 많이 달면 오히려 스팸처럼 보인다.

```
[현장 사례 or 숫자 1문장]

[블로그 핵심 3줄 요약]

전문은 여기서 보실 수 있습니다.
👉 [블로그 URL]
```

**OG 이미지가 안 뜨면 링크 클릭률이 반토막 난다.** 블로그(워드프레스)의 대표 이미지가 1200×630으로 지정돼 있는지 확인하라고 안내한다. 지정이 안 돼 있으면 `ax-blog-post` 쪽에서 먼저 설정해야 한다.

**대표 이미지가 없으면** 나노바나나용 프롬프트를 하나 만들어준다. 인스타 카드와 달리 **글자를 넣지 않는다** — 페이스북이 링크 카드에 제목을 자기 폰트로 얹기 때문에 이미지에도 글자가 있으면 두 번 겹쳐 보인다. 16:9로 뽑는다.

```
🖼️ 페이스북 OG 이미지 (16:9)
```
가로 16:9 비율의 사실적인 사진을 만들어줘. 한국의 중소기업 사무실에서 40대 대표가
책상에서 노트북과 서류를 검토하는 옆모습. 창으로 들어오는 부드러운 자연광,
차분하고 사려 깊은 분위기, 배경은 얕게 흐릿하게.
이미지 안에 글자나 로고는 절대 넣지 마.
```

## 발행 순서 (같은 날 3채널 도배 금지)

같은 날 세 채널에 같은 내용을 올리면 팔로워가 겹치는 만큼 피로도만 올라간다. 시차를 둔다.

| 시점 | 채널 | 목적 |
|---|---|---|
| **D-day** | 블로그 발행 + 쓰레드 | 인지 |
| **D+1** | 인스타 카드뉴스 | 저장·브랜딩 |
| **D+3** | 페이스북 (링크) | 유입 |

**예약 발행 현황 (2026년 8월 기준)**
- 페이스북 + 인스타 → Meta Business Suite에서 동시 예약 가능
- **쓰레드는 인스타 예약분이 자동 크로스포스팅 되지 않는다.** Business Suite에서 단건 예약은 되지만 대량 예약은 안 된다. 앱에서 직접 올리거나 Buffer 등 서드파티(Threads API 기반)를 쓴다.

이 정보는 플랫폼 정책이라 바뀔 수 있다. 사용자가 예약 방법을 구체적으로 물으면 웹 검색으로 현재 상태를 확인하고 답한다.

## 출력 형식

`.md` 파일 하나에 아래 순서로 담는다. 사용자가 채널별로 바로 복붙할 수 있게 **구분선으로 확실히 나눈다.**

```
# SNS 3채널 원고 — [주제]
원본 블로그: [제목 / URL]

## 📦 추출한 재료
(4가지)

---
## 1️⃣ 쓰레드  ← D-day
### 이어달기 [1]~[4]
### 첫 답글 (링크)

---
## 2️⃣ 인스타 카드뉴스  ← D+1
### 카드 카피 한눈에 보기 (표)
### 🍌 나노바나나 프롬프트 — 카드 1(풀) → 카드 2~N(이어쓰기), 순서대로 붙여넣기
### 캡션 + 해시태그
### ⚠️ 프로필 링크 확인

```

## 톤 & 매너

- **채널별로 톤을 바꾼다.** 쓰레드는 구어체 1인칭 관찰자, 인스타는 짧고 단정적, 페이스북은 정중한 정보 전달. 세 채널이 같은 톤이면 변주를 안 한 것이다.
- **쉬운 언어**: "거버넌스" → "회사 차원의 사용 규칙", "Shadow AI" → "직원이 회사 몰래 쓰는 AI"(첫 등장 시 풀어주고 이후 용어 사용).
- **과장·불안 조장 금지.** "지금 안 하면 망합니다" 같은 소구는 쓰지 않는다. 회사 원칙이다. 대신 구체적 상황을 보여줘서 스스로 판단하게 한다.
- **실용 How-to가 개념 설명보다 잘 먹힌다.** 카드뉴스는 무조건 "번호 매긴 실무 팁" 구조로 간다.

## 자가 점검 (출력 전 확인)

**공통**
- [ ] 세 채널 원고가 서로 다른 문장인가 (복붙 변주가 아니라 실제 재작성인가)
- [ ] 등장하는 수치에 출처가 붙어 있는가. 없으면 뺐는가
- [ ] 과장·불안 조장 표현이 없는가
- [ ] 3채널 모두 자가진단·axpartner.co.kr로 이어지는가

**쓰레드**
- [ ] 첫 게시물이 150자 이내인가 (최대 500자를 넘지 않는가)
- [ ] 토픽태그가 1개인가
- [ ] 링크가 본문이 아니라 첫 답글에 있는가
- [ ] 홍보 톤이 아니라 관찰자 톤인가

**인스타**
- [ ] 카드 5~7장, 규격(1080×1350 또는 1080×1080) 명시했는가
- [ ] 카드당 메시지가 1개인가
- [ ] 캡션 첫 2줄만으로 클릭할 이유가 생기는가
- [ ] 해시태그 5~10개인가
- [ ] 마지막 카드 CTA와 프로필 링크 일치 안내를 넣었는가
- [ ] 이미지는 프롬프트까지만 제공했는가 (만들었다고 말하지 않았는가)
- [ ] 나노바나나 프롬프트에 **한글 카피가 실제로 박혀** 있는가 (빈칸·자리표시자가 없는가)
- [ ] "철자 그대로, 오타 없이" 지시와 글자 위치 지정이 들어갔는가
- [ ] 카드 1은 풀 프롬프트, 2번부터는 이어쓰기 프롬프트인가
- [ ] 코드블록 안에 설명·주석이 섞이지 않았는가 (붙여넣기 한 번으로 끝나는가)

**페이스북**
- [ ] 본문 3~5줄인가
- [ ] 블로그 링크가 들어갔는가
- [ ] OG 이미지 1200×630 안내를 넣었는가 (직접 만들 경우 16:9, **글자 없이**)

## 완료 후

- `.md` 파일을 사용자에게 전달한다.
- **이미지 만드는 법을 한 줄로 안내한다**: "gemini.google.com에 로그인한 상태에서 카드 1 프롬프트를 붙여넣고, 이미지가 나오면 같은 대화에 카드 2, 3… 을 순서대로 붙여넣으세요. 대화를 새로 열면 스타일이 달라집니다."
- 한글이 깨져서 나오면 알려달라고 한다. 그때 배경 전용 프롬프트(글자 없음)로 다시 뽑아준다.
- 발행 후 2주가 지나면 성과 데이터(쓰레드 조회·인스타 저장·페이스북 링크 클릭)를 가져와 달라고 안내한다. 성과 진단은 `ax-cmo`에서 이어서 한다. **데이터 없이 성과를 추정하지 않는다.**
