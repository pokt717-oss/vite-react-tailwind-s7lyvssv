## 확정된 결정
- 이미지는 채널별로 다른 스타일, 총 8장
  - 네이버: `naver-opus55-*.png` 4장, 플랫 일러스트 (프롬프트는 네이버 원고의 🖼️ 표시)
  - 워드프레스: `wp-opus55-*.png` 4장, 실사 (프롬프트는 워드프레스 원고 상단 이미지 표)
- 모든 이미지 16:9. 워드프레스 대표 이미지는 1200×630
- 워드프레스 내부링크: 홈페이지(AX 4대 요소)와 /claude-fable5-pricing-sme-ax/ 글로 연결. 거버넌스 전용 글이 있으면 그 주소로 교체

## 남은 작업 (브라우저 필요)
1. 제미나이(로그인됨)의 나노바나나로 이미지 8장 생성 → 이 폴더의 `images/`에 저장
2. 네이버 원고의 이미지 표시에 파일 경로 반영
3. 워드프레스(axpartner.co.kr, 로그인됨)에 워드프레스 원고 입력
   - 이미지 4장 업로드 + alt 텍스트, 대표 이미지 지정
   - Rank Math: 포커스 키워드, SEO 제목, 슬러그, 메타 설명 입력
   - 임시글로 저장만 함. 발행 금지
4. 변경사항을 `claude/opus-5.5-naver-wordpress-nkxq6v` 브랜치에 커밋·푸시
